# 安卓账本小屋（尚待安卓编译和真机验收）
此版本离线打包小屋；无需登录。账目保存在应用私有存储，组件读取同一份记录，不另存总额。
浏览器、云端基础账本和此安装包的数据尚不互通。卸载应用会删除本地账目。
组件按手机当地日期累计支出，不含收入；记账后立即刷新所有组件。系统定时刷新最短30分钟，跨午夜后台刷新可能延迟，打开应用会立即刷新。
人物趴姿素材尚未加入，目前是简约金额卡片。

## 构建
安装 Android Studio，打开本目录，使用 JDK 17、Android SDK 35、Gradle 8.11.1（本项目未包含 wrapper）。
在有 Gradle 的终端执行 gradle :app:assembleDebug。
安装包在 app/build/outputs/apk/debug/app-debug.apk。测试包不作为正式上架包。
正式长期更新需要保存同一份签名密钥、保持 applicationId 不变并增加 versionCode；切勿覆盖丢失签名。
更新网页不会自动更新离线 APK，需要重新构建安装包。

## 真机验收
添加两份组件；记支出0.10和0.20，应均显示0.30；记收入不增加支出。
关闭重开、重启手机后账目仍在；无网记账仍刷新组件。
测试跨日、时区切换，今日支出只累计本地当天。
点击组件应进入小屋。禁止外部页面加载到原生桥接的 WebView。
